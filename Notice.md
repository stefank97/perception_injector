# Notice

This package uses or depends on the following third-party packages:

- **Stage**  
  2D simulation environment used for running the robot simulation.
- **Stage-ROS2**  
  2D simulation environment used for running the robot simulation.
- **tuw_common**  
  Geometry utilities and helper functions used for coordinate transforms.
- **tuw_nav2**  
  Extensions and utilities for the Navigation2 framework.
- **dsniff**  
  Network analysis and penetration-testing toolkit used for security-related experiments inside the container.
- **Fast DDS Discovery Server (fastdds-tools)**  
  Used for discovery, domain configuration, and participant coordination in the distributed simulation.
- **nftables**  
  Firewall and packet filtering framework used for network manipulation inside the container.
